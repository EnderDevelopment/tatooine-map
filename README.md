# TatooineMap

TatooineMap is a Roblox script that creates a detailed map of Tatooine, including weather effects and player interactions. This script is designed to enhance the immersive experience of Tatooine in Roblox games by providing a comprehensive map with dynamic weather conditions and interactive player elements.

## Install

1. Download the TatooineMap script from the GitHub repository.
2. Open your Roblox Studio project.
3. Navigate to the `ServerScriptService` folder and create a new folder named `TattoineMap`.
4. Place the `MapLoader.server.lua` and `WeatherController.server.lua` scripts into the `TattoineMap` folder.
5. Navigate to the `StarterPlayerScripts` folder and create a new folder named `TattoineMap`.
6. Place the `PlayerController.client.lua` and `UIManager.client.lua` scripts into the `TattoineMap` folder.
7. Navigate to the `ReplicatedStorage` folder and create a new folder named `TattoineMap`.
8. Place the `MapData.module.lua` and `WeatherData.module.lua` modules into the `TattoineMap` folder.

## Use

1. Run your Roblox Studio project to load the Tatooine map.
2. The map will be generated based on the data in `MapData.module.lua`.
3. Weather effects will be applied based on the data in `WeatherData.module.lua`.
4. Player interactions will be handled by `PlayerController.client.lua`.
5. The user interface will be managed by `UIManager.client.lua`.
